# SmartEvent – Senior Status Format

## Module 1 – User Authentication
Registration, bcrypt password hashing, JWT login, protected routes, profile and Pydantic validation.

## Module 2 – Event Discovery System
Event listing, event details, category filtering, title search and event cards.

## Module 3 – Ticket Booking System
Booking API, automatic total price, ticket availability, sold-out prevention and booking history.

## Module 4 – QR Code Ticket System
Unique ticket code, QR generation, ticket retrieval and QR verification.

## Module 5 – Event Reminder Notifications
Booking confirmation notifications, notification listing, unread count and mark-as-read.

## Module 6 – Frontend UI Structure
React/Vite pages, Axios integration, protected navigation, responsive UI, loading/error states and reusable components.

## Final
Backend/frontend integration, security testing, API testing, README and GitHub submission.
